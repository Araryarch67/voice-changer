## Update — export for RVC v1 and no-f0 (2026-11-12)

- There are now 24 templates: v1/v2 × f0/no-f0 × 32/40/48 kHz × plain/realtime. They are generated by `tools/dev/make_rvc_templates.py` from the reference `onnxExporter` classes and stored zlib-compressed (1.4 MB in total; 16 MB uncompressed).
- No real v1 or no-f0 checkpoint was available. `tools/dev/verify_rvc_export.py` builds a random-weight fp16 checkpoint for each of the 12 architectures (v1 without a `version` key, like old v1 files) and exports it with the Rust CLI. It then runs ONNX Runtime with the random-noise nodes zeroed and compares against:
  - PyTorch's forward pass with randomness patched to zero (all 24 variants): max |diff| ≤ 3.3e-7, with output peaks of 0.015 to 0.076.
  - The reference `export2onnx` procedure (no constant folding, then onnxsim; plain decoders, 12 variants): max |diff| ≤ 3e-8.
  - Metadata (`embChannels`, `f0`, `useFinalProj`), output shape and `onnx.checker`: OK for every variant.
- For the standard configs (`resblock "1"`), the reference `infer_realtime` does not crop, so realtime and plain outputs are equal.
- `cargo test -- --include-ignored`: 32 passed. clippy and the `--no-default-features` check passed.
